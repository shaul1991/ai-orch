# Backend Implementation Skill

## Purpose

Use this skill for backend implementation tasks under approved SDD scope.

## Rules

- Implement only approved tasks from `tasks.md`.
- Do not invent domain rules.
- Do not change API contracts unless explicitly required.
- Do not modify authentication or authorization behavior unless explicitly required.
- Do not perform broad refactoring outside the approved scope.
- Add or update tests for changed behavior.
- Prefer small, reviewable changes.

## Required Output

After implementation, summarize:

- Changed files
- Tests added or updated
- Tests executed
- Risks
- Human review points

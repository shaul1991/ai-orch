# Self Review Skill

## Purpose

Use this skill after implementation and before PR draft.

## Review Checklist

Check:

1. Requirement coverage
2. Acceptance criteria coverage
3. Test coverage
4. Regression risk
5. Security impact
6. Performance impact
7. Data model impact
8. API contract impact
9. Human decision points

## Required Output

Create or update:

`docs/specs/{feature}/self-review.md`

The review must include:

- Requirement coverage table
- Acceptance criteria coverage table
- Changed files
- Test results
- Risks
- Human review checklist

# Self Review Skill

## Purpose

Use this skill after implementation and before PR draft.

## Review Checklist

Check:

1. Requirement coverage
2. Acceptance criteria coverage
3. Traceability coverage
4. Test coverage
5. Regression risk
6. Security impact
7. Performance impact
8. Data model impact
9. API contract impact
10. Human decision points

## Required Output

Create or update:

`docs/specs/{feature}/self-review.md`

The review must include:

- Requirement coverage table
- Acceptance criteria coverage table
- Traceability coverage table
- Changed files
- Test results
- Risks
- Human review checklist

# AI Orch Help

`scripts/ai-orch.sh help`로 위임한다.

## Instructions

1. AI Orch에서 사용할 수 있는 command와 flow 목록을 표시한다고 간단히 설명한다.
2. repository root에서 `scripts/ai-orch.sh help`를 실행한다.
3. 사용 가능한 flow와 주요 사용 예를 요약한다.
4. 실행 flow를 선택하지 않는다. 사용자가 다음 command를 선택하도록 멈춘다.
